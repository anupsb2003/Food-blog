## ✨ About The Project

The **Food Blog Website** is a creative and responsive web experience designed for food lovers.

It presents food stories, recipes, food categories, and visually engaging content through a clean and modern interface.

The website focuses on:

- 🍕 Attractive food presentation
- 🍜 Responsive design
- ☕ Smooth animations
- 🌶️ Creative layouts
- 📱 Mobile-friendly experience
- 🎨 Modern UI/UX
- ⚡ Fast performance using Vite

---

## 🚀 Features

- ✅ Modern and responsive user interface
- ✅ Beautiful food-focused design
- ✅ Animated hero sections
- ✅ Interactive navigation
- ✅ Food category sections
- ✅ Recipe and food content sections
- ✅ Responsive layout for mobile, tablet, and desktop
- ✅ Reusable React components
- ✅ TypeScript-based development
- ✅ Fast development with Vite

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/anupsb2003/Food-blog.git
```

### 2. Navigate to the Project

```bash
cd Food-blog
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:5173
```
